# 🎓 AcademiaAI — AI-Powered Academic Assistant

> A full-stack web application that helps students learn faster using AI — offering instant explanations, concept maps, visualizations, flashcards, and PDF export.

## ✨ Features

- 🤖 **AI-Powered Q&A** — Four modes: Explain, Summary, Step-by-Step, Flashcards
- 🗺️ **Concept Map Visualization** — Interactive graphs using vis.js
- 📊 **Data Charts** — Auto-generated with Matplotlib
- 🎬 **Video Integration** — Related YouTube videos embedded
- 🔐 **User Authentication** — Secure login/signup with bcrypt
- 💾 **History Tracking** — All your Q&A saved in MongoDB
- 📄 **PDF Export** — Download answers as formatted PDFs
- 🌙 **Dark / Light Mode** — Theme persists across sessions
- 🧪 **Unit Tested** — Pytest test suite included
- 📱 **Responsive Design** — Works on mobile and desktop

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | Python, Flask, Flask-Login |
| **Database** | MongoDB (via Flask-PyMongo) |
| **AI** | OpenAI GPT-4o-mini API |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Visualization** | vis.js, Matplotlib |
| **PDF** | ReportLab |
| **Testing** | Pytest |
| **Auth** | bcrypt password hashing |
